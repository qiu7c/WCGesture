# 悬浮底栏

2026-10-29，源码接入，待 iOS 编译和真机验证。默认关闭。

入口：界面类功能 → 悬浮底栏。顶部实时预览支持浅色/深色，外观、位置与圆角、选中滑块与手势、角标、自定义颜色默认折叠。设置单页一张卡片，无独立说明小字。版本保持 1.0.0。

## 证据与实现

参考用户提供的 WeChatX 2.4-5 静态反汇编，dylib SHA256：`5c64e38cf8c5c63f80d21cb849133921ca00e1d66eea766bd799f1ca0f798d10`。

- `0x3fd0fc`：原生布局后增加背景，原生 tab item 保持原父视图，不另造业务导航。
- `0x3fe07c..0x3fe16c`：背景 x=30−Width，y=Y−12，宽=bar.bounds.width−2×x，高=Height+58，半径=max(0,高/2+Radius)。默认 Width=-1、Y=-4、Height=12、Radius=-1。
- `0x3fe1ac..0x3fe524`：按实际 item 数均分，item 高=min(49,背景高)，纵向居中。
- `0x3fce0c`：选中滑块按均分区域内缩3点；`0x3fc640`：横向拖动、0.15秒速度投影和原生按钮 TouchUpInside。
- `0x3fd9b8..0x3fdf68`：纯色、磨砂、浅色纯色/深色磨砂、自定义颜色四种样式；模糊原始 style 数值6/7。
- `0x3ffad0`：原生图标弹性/摇摆/果冻/心跳/跳动；`0x400870`：按角标文字区分红点和数字，隐藏时宽高归0，保留原点。
- 长按第二项0.5秒打开外观设置；设置变更通过 One Wx 既有通知同步。

微信 8.0.79 的 MMTabBar、MMTabBarItemView、MMBadgeView 方法签名已对照本地原生头文件。私有类仅声明和运行时查找，避免直接引用其 ObjC 类符号造成链接失败。scrollEdgeAppearance 仅 iOS15+ 且原方法存在时安装运行时 Hook。

## One Wx 适配与取舍

- 尺寸按既有界面比例缩放一次；窄窗口保证每项至少24点×比例的宽度。原生 bar.frame、导航栏、内容安全区和分组导航栏不改动。
- 深色优先使用微信 MMDarkModeConfigUtil.isDarkMode，模式更新复用已有 Hook；系统 trait 变化也请求底栏重绘。
- 保留微信原生 item、角标和 UIControl target/action。只在原生按钮数量与 item 对应时启用拖动；取消拖动恢复当前选中项，不提交新页面。
- 保存实际修改过的原生 frame/hidden/alpha，下一次原生布局前恢复；着色只恢复本功能改过的图像和颜色，不回写未改过的角标图像。原生选择/图片刷新前恢复本功能模板着色，再让原生更新。
- 背景颜色、背景图、阴影图和 appearance 保存最近一次原生 setter 输入，关闭后恢复。透明 appearance 只首次安装；后续 setter 转发时处理，避免布局内反复设置 appearance 形成刷新循环。
- 背景不透明度作用于纯色背景或模糊层，文字与图标不受影响；滑块不透明度独立控制。
- 修正来源果冻动画6个值对应5个 keyTimes 的不匹配，果冻使用均匀时间点；其余关键帧沿用已解出的数组。选中移动使用0.3秒弹簧动画。
- 长按使用 One Wx 自己的设置页与预览，以 page sheet 打开；不是运行时调用来源插件的私有设置类。
- 预览和运行时共享同一背景/滑块渲染与选中动画。预览图标用系统符号示意，实际页面保留微信图标；预览主题选择不修改微信主题。
- 不迁移 WeChatX 禁用系统 interactivePop、合成返回手势和接管导航返回的附带逻辑；底栏随微信原有页面和键盘生命周期显示/隐藏。
- 不加入反编译未发现实际消费的 ButtonScale 滑杆，不混入尚未解清的黄白快捷动作。

22个新配置使用 `com.qiu7c.onewx.interface.floating-tab.*`，均有 Core 声明、定义、默认值、设置行与口令导入导出。旧口令别名不改动。数值类型、有限性和范围在配置读入边界统一校验，内部直接使用。

## 验收

静态检查只确认结构、引用、Hook 去重、配置闭合和几何关系，不等于成功编译或运行。

设备需验证：首次冷启动、连续切换、未读数量实时变化、红点/数字分别隐藏、四种样式及微信独立深色模式、界面缩放、长按调节、拖动结束/取消、关闭功能/总开关恢复，以及聊天页/设置页/小程序/键盘与交互返回的原生显隐。该实现没有覆盖宿主显隐规则，仍需确认实际微信版本的最终行为。
