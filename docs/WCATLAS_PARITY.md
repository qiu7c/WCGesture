# WCAtlas 聊天设置移植对照

2026-10-25。对照本地 WCAtlas 的 `WCAtlasSettingsCatalog.m`、
`WCAtlasSettingsActions.m`、`WCAtlasAntiRevoke.m`、`WCAtlasMessageTime.m` 和
`Tweak.xm` 移植。以下是源码实现覆盖，不代表已通过编译或真机验证。

## 防撤回

| WCAtlas 设置 | One Wx 设置 / 实现 |
|---|---|
| 防撤回 | 原有开关键保留，默认关闭 |
| 防撤回提示方案 | 消息下方 / 气泡旁 |
| 本地提示模板 | 多行编辑、占位符替换、恢复默认 |
| 提示外观预览 | 独立调节页：提示文字、X/Y 拖动、滑杆、精确数值、重置 |
| 浅色模式提示颜色 | 根据当前提示方案编辑本地提示或气泡旁提示颜色，支持透明度 |
| 深色模式提示颜色 | 独立颜色，支持透明度 |
| 回复撤回者 | 默认关闭；手动开启后自动向对应会话发送回复模板 |
| 回复时间限制 | 不限制、1/5/30 分钟、1/24 小时；不影响本地拦截 |
| 回复消息模板 | 多行编辑、占位符替换、恢复默认 |
| 防撤回记录中心 | 按联系人、会话或摘要搜索；展示消息类型与时间 |
| 本地保存撤回记录 | 默认仅内存；开启保存摘要/分类，关闭移除持久化归档 |

原有拦截流程已移植：从 `onNewSyncNotAddDBMessage:` 接收撤回通知，解析
session / newmsgid / replacemsg，查询原消息并排除自己撤回。消息下方方案创建
类型 10000 的系统消息，发送时间为原消息时间加 1，调用
`AddLocalMsg:MsgWrap:fixTime:NewMsgArriveNotify:`（YES / NO）。气泡旁方案按原
消息标识保存提示记录，通过气泡锚点绘制标签。原消息缺失或处理异常时保留原处理。

与 WCAtlas 一样，自动回复目标在群聊中为该群；时间限制只作用于回复。媒体摘要
按消息类型显示，不复制媒体。记录列表最多 500 条；侧边提示映射和本地系统提示内容
沿用原实现的容量控制。原消息自身由微信管理。

本地系统提示浅/深色通过独立 `SystemMessageCellView` Hook 应用；关闭功能或复用
为其他消息后恢复原色。气泡旁提示只放在长消息尾段，并避让已显示的消息时间。

## 消息时间

| WCAtlas 设置 | One Wx 设置 / 实现 |
|---|---|
| 消息时间显示 | 原有开关键保留，默认关闭 |
| 时间显示位置 | 头像下方 / 消息右侧，互斥；旧版本只有气泡旁的配置保留原模式 |
| 消息旁垂直位置 | 顶部 / 中间 / 底部；在独立预览页调节 |
| 头像时间间距 | -6 到 8；在独立预览页拖动或输入 |
| 时间格式 | 自定义 yyyy、MM、dd、E、HH、mm、ss 与分隔文字，最多 64 字符 |
| 时间字号 | 8–18，默认 10 |
| 时间文字加粗 | 两种显示模式共用 |
| 浅色模式时间颜色 | 独立颜色，支持透明度 |
| 深色模式时间颜色 | 独立颜色，支持透明度 |

移植了消息标识核对、父消息回退、头像/气泡锚点查找、分段选择、重复标签清理、
Cell 复用失效代次、下一主循环与 0.12 秒延迟刷新。头像模式只显示在首段，气泡旁
模式只显示在尾段。标签不写入聊天数据库。

One Wx 增加了气泡旁 X/Y 微调（-80 到 80）。预览和实际标签共用日期格式化、
字体颜色以及头像/气泡旁坐标函数；实际气泡旁空间不足时隐藏，避免遮住内容。
预览为示意，不替代原生 Cell 的真实高度/缓存验证。

## 界面与结构

聊天输入栏圆角也已移植：总开关、输入框内部圆角、内部程度、外部工具栏圆角、
外部程度（0–40，默认 18/22）。实现独立于布局/分割线模块。开启时保存半径、曲线、
裁切状态；关闭或视图移出窗口时恢复。原生目标为 MMGrowTextView 和实测外部容器，
按当前高度限制半径，避免输入框长高时仍停留在旧半径。预览共用实现并提供多行模式。

- 首页恢复显式圆角卡片背景。搜索为同背景自绘文本框，不使用原生 UISearchBar。
- 二级菜单取消竖杠，以字号、缩进和右侧折叠箭头表达层级。旧设置页内嵌预览已移除。
- 名称统一为“界面大小”；子项“包含插件界面”默认关闭，控制 One Wx 设置与弹窗
  的字体、行高等尺寸。界面大小仅提供实际设置，不提供模拟布局预览。
- 时间位置、防撤回外观和输入圆角共用整页聊天预览，预览与调节面板之间留 12pt。右上角打开底部调节面板，提供
  系统/浅/深外观、拖动、滑杆、精确输入与重置。`WCGestureCreateAdjustmentEditor` 接受自定义预览
  UIView 和参数描述，供后续功能复用。
- 后端留在 `Features/AntiRevoke/`、`Features/MessageTime/`；界面位于 `UI/`；
  新的颜色/格式辅助集中在 `Core/WCGestureAppearance.m`，跨模块均经 API 伞头。
- 本轮 `Tweak.x` 只增加防撤回设置刷新调用，没有放入功能逻辑。

## 预览坐标修正

按用户提供的真实消息层级，393 点宽的短消息行高 53，头像尺寸 42，左/右头像
分别位于 (9,2)/(342,2)。宽 50、高 15 的时间标签应为 (5,38)/(338,38)。
新预览为每条样例创建独立 UIView，使用与真实消息相同的局部 bounds 和居中
对齐；不再将整块预览的高度当成消息行高。调节值仍受真实行边界约束，短行可能
限制可见的纵向移动范围；长行可以体现更多间距变化。

样例头像通过 WCAtlas 使用的微信原生 MMHeadImageHelper 工厂获取当前账号头像，两侧均不再用占位图。
聊天正文为虚构样例，导航/输入栏为自绘近似，不实例化真实聊天控制器或发送消息。
本地算式回归符合上述框坐标；完整外观、头像加载、导航恢复和抽屉操作仍需真机确认。
