## 推荐顺序

### 先收尾当前版本

先验证头像加载、圆角恢复、语音转发、菜单管理和预览导航，再补齐配置备份范围。当前新增功能还没有完成真机验收。

### 第一批：已在本轮接入，待验证

1. 隐藏群标题尾部、截屏分享浮层、“我”页面入口管理：界面更简洁，功能边界较清楚。
2. 朋友圈图片圆角：与已经迁移的头像/输入栏圆角组成一致的视觉设置，适合局部样式预览。
3. 聊天记录搜索、引用消息定位、菜单 +1：常用操作，尽量复用已有消息 API。
4. 精确朋友圈时间：功能集中，适合先补当前较空的朋友圈分类。
5. 自动原图、语音自动转文字：日常收益明显，但异步与发送入口应单独验证。

### 第二批：按需求选一组做完整

- 朋友圈手动转发已按用户选择接入，待验证；保存/评论防删除仍待选择。
- 指定会话发送前确认已按用户选择接入，先完成不同媒体发送入口与取消行为的设备验证。
- 多选导出与图片保存，形成完整的内容整理流程。
- 快捷回复/消息库，形成独立模块后再考虑 TTS、定时发送与媒体转语音。

### 后续再做

首页分类、胶囊顶栏、定时消息/关键词自动回复、虚拟定位和语音编解码。它们跨越的微信入口更多，难以靠局部样式检查完成验证，不适合和当前 UI 收尾混在同一批提交。

界面大小继续只提供实际设置与设备验证，不恢复模拟布局预览。所有后续功能仍按 CONVENTIONS.md 拆分模块。
